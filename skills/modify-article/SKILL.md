# Modify Blog / Article

Read [shared workflow](../../references/workflow.md), [Writer](../../agents/writer.md), and relevant [technical standards](../../references/technical-standards.md). Resolve the existing article path and requested change. Read the full article, editorial notes, examples, and asset inventory before editing.

Delegate the scoped change to the Writer. Preserve unrelated content, assets, and created date. Update updated date and invalidate the previous reviewed status. For an existing article outside the package convention, retain the original file and explain the proposed package migration; do not silently move it. Review can work on an external Markdown file without migration.

Validate the resulting package. Delegate review with [Reviewer](../../agents/reviewer.md), including changed areas and any surrounding claims affected by them. Follow the shared correction limit and save the report using [review template](../../templates/review.md). Return changed files, verification, and outstanding findings.
